# Доля ВИЭ в выработке электроэнергии

За 2010–2021 годы доля возобновляемых источников в выработке выросла с 35,47% до 89,04% в Люксембурге и с 4,04% до 56,37% в Камбодже. В отчёте 199 сопоставимых экономик.

[Книга Excel](report.xlsx) · [Запрос SQLite](analysis.sql) · [Результаты CSV](summary.csv)

Два года соединяются по коду экономики. Excel считает разность долей в процентных пунктах. Лист «Сверка» показывает пропуски по году и расхождения между формулами и SQL.

Электроэнергия из возобновляемых источников включает гидроэнергетику. Это доля выработки, а не доля установленной мощности или энергопотребления. В этой выгрузке нет наблюдений за 2022–2023 годы.

**Источник.** Всемирный банк, World Development Indicators: [`EG.ELC.RNEW.ZS`](https://data.worldbank.org/indicator/EG.ELC.RNEW.ZS). В `source.csv` оставлены национальные ряды за 2010–2023 годы; региональные и глобальные агрегаты исключены. [Лицензия набора](https://datacatalog.worldbank.org/infrastructure-data/search/dataset/0037712/world-development-indicators). Дата выгрузки: 23 ноября 2026 года. Пустая ячейка означает отсутствие наблюдения.
